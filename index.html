Import the NexLed configuration to your global Tailwind environment to unlock the premium token sets. 

// index.html
<script src="https://cdn.tailwindcss.com"></script>
<script src="src/config-cdn.js"></script>

Follow the Atomic Methodology. Use Atoms for basic tasks, and never hardcode shadow or radius values. Always reference tokens like shadow-btn-default.
